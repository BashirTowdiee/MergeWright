# Support

MergeWright is currently pre-release. Support is handled through GitHub issues and pull requests.

## Questions

For usage questions, open a GitHub issue and include:

- what you are trying to do
- the command or workflow involved
- your operating system
- Node and npm versions
- relevant configuration, with secrets removed

## Bugs

Use the bug report issue template when behaviour is reproducible.

Include logs, run artefacts, terminal output, and the exact command where possible.

## Feature requests

Use the feature request issue template for new workflow, CLI, TUI, backend, or documentation ideas.

Keep requests focused on one problem or outcome.

## Security issues

Do not open public issues for security-sensitive reports. Follow `SECURITY.md`.

## Maintainer response

Response times are best effort while the project is pre-release.
