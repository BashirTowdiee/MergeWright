# Plans

This directory contains product and implementation roadmaps for MergeWright.

## Roadmaps

| Plan | Purpose |
| --- | --- |
| [Enterprise roadmap](enterprise-roadmap.md) | Long-term productisation roadmap for moving MergeWright from a local AI delivery harness into an enterprise-grade engineering platform. |
| [TUI write capability roadmap](tui-write-capability-roadmap.md) | Implementation roadmap for moving the TUI from read-only inspection to safe write-capable orchestration through a service-first command layer. |

## Usage

Use these plans as planning inputs only. Convert each stage into small executable tasks before implementation, and keep implementation PRs scoped to one slice at a time.
